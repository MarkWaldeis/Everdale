# Everdale UI kit

Painted Supercell / Everdale look for every menu.

## Palette
- Wood plank `#e08a38` / highlight `#f3c27a`
- Card green `#6fbf3a` → `#4ea31f`
- Name text cream `#fff8dc`
- Portrait backdrop `#1f5a28`

## Files
- `panel-wood.jpg` — full-width dock / future inventory bars
- `card-frame.jpg` — empty portrait frame
- `portrait-bewohnerin.jpg` — first villager (3D clay)
- `btn-hire.jpg` — hire / plus tile
- `pin-empty.jpg` — resource pin
- `icons-row.jpg` — wood, axe, stone, pumpkin, apple, wheat

## Rules
- Put labels in HTML, never in the pictures.
- New menu screens reuse the wood plank + green tiles.
- New villagers: same 3:4 bust, same lighting, then drop into `.worker-frame`.
